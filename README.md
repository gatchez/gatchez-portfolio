# Gatchez — Personal Portfolio

A personal portfolio website presenting my software development 
projects, technical interests, academic background and experience.

## Overview

The website is designed as a lightweight, responsive and accessible professional portfolio.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub
- Cloudflare Pages (planned hosting)

## Project Structure

```text
gatchez-portfolio/
├── index.html
├── 404.html
├── robots.txt
├── _headers
├── README.md
├── .gitignore
├── assets/
│   ├── css/
│   ├── js/
│   ├── images/
│   └── favicon/
└── .github/
    └── workflows/
```

## Local Development

No build tools or package installation are required.

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in browser.

## Deployment

The intended hosting platform is Cloudflare Pages, connected to the GitHub repository.
